# Scripts

## HUKPwd.applescript

Automates retrieving the HUK password from 1Password and entering in one of the HUK Citrix Windows:
* If Citrix Viewer is active, it asks whether to also type in the user name and then types it the password
* otherwise, if Citrix Workspace is active, it types the user name, password and jumps back to the one-time-code field.
